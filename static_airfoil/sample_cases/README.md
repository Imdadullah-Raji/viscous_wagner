# Sample cases

Dictionaries only (`0/`, `constant/` without the mesh, `system/`), copied from generated cases.
Every case is regenerated by the drivers, so these are for reading, not for running in place.

| folder | made by | mesh |
|---|---|---|
| `steady_NACA0012_re500_aoa4` | `make_steady.sh <case> 500 4 <mesh> 6000` | `M2_ns160_nr180_b025.msh` |
| `unsteady_NACA0012_re500_aoa20` | `make_case.sh`, then `run_staged.sh` (its `controlDict` is in its final phase-2 state) | `M2_ns160_nr180_b025.msh` |

The mesh is Re-specific (first cell `h1 = 0.05/sqrt(Re)`), 63,360 cells:

```bash
cd meshing && /home/raji/miniconda3/envs/research/bin/python mesher.py ../meshes/M2_ns160_nr180_b025.msh \
    --re 500 -r 30 --nr 180 --ns 160 --nte 32 --bump 0.25          # add --naca 0006 for NACA0006
```

The angle is set by rotating the freestream. It appears in `0/U` (`internalField` and
`freestreamValue`), in the force directions in `system/functions` and in `Cp`'s `UInf`.
`make_case.sh` writes all three from one value; editing one by hand gives a plausible but wrong C_L.
